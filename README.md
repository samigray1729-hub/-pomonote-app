# PomoNote

端末内だけで動作する、スマートフォン優先のポモドーロタイマーPWAです。

## 起動

Service Workerを利用するため、ローカルHTTPサーバーから開いてください。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/` を開きます。

## データ

- 記録と設定はブラウザーの `localStorage` にJSONとして保存します。
- 設定画面からJSONバックアップとCSV記録を書き出せます。
- 外部サーバー、外部API、外部フォントは使用していません。

## バックグラウンドタイマー

終了予定日時を保存して残り時間を復元します。ブラウザーやOSがPWAを停止した場合、音と通知は保証されないため、再開時に完了・中断・再開を確認します。
